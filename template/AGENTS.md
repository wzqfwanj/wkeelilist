# AGENTS.md · 开发智能体使用说明

本文件夹是「黑白极简页面模板」的交付包。收到本文件夹的智能体请**直接按本文件开发**，不要重新设计视觉风格。

## 你要做的事

在 `index.html` / `style.css` / `app.js` 的基础上，实现用户描述的新系统页面。

## 必须满足的需求（硬性）

1. **主题切换功能保持不变**
   - 保留右上角图标按钮，保留 明 / 灰 / 暗 三态循环（明 → 灰 → 暗 → 明），图标随主题变化
   - 保留 localStorage 记忆（键名 `template-theme`）和 `?theme=light|gray|dark` 直接打开
   - 保留三套 CSS 变量：`:root`（明）、`[data-theme="gray"]`、`[data-theme="dark"]`
   - **不得**改成两态、不得删掉按钮、不得换成文字按钮、不得改 `data-theme` 的取值
2. **页面标题替换为系统名称**
   - `<h1>` 文本改为系统名称
   - 浏览器标签 `<title>` 同样改为系统名称
3. **副标题介绍系统做什么**
   - `.sub` 改为一句话说明（建议 ≤ 30 字），不要留空、不要省略
4. **其余地方自行排版**
   - 在 `.content` 内按需组织页面内容；可以新增 HTML / CSS，但要延续本模板的设计语言

## 技术与风格约束

- 纯 HTML / CSS / JS，零依赖、零构建；不引入框架、CDN、网络字体、外链图标
- 颜色只用 CSS 变量（`--bg / --fg / --muted / --line / --hover`），不要新增硬编码色值；保持黑白 / 灰调
- 极简：细线分隔、留白、无阴影、无彩色色块（状态点允许半填充/半透明）
- 移动端可用：窄屏不得横向滚动，沿用 560px 断点
- 不改动 `app.js` 里的主题逻辑与图标定义

## 验收清单（提交前逐条自测）

- [ ] 点击主题按钮：明 → 灰 → 暗 → 明 循环，图标随主题变化
- [ ] 刷新后主题保持；`?theme=gray` 直接打开灰主题；`?theme=dark` 打开暗主题
- [ ] 页面 `<h1>` = 系统名称；浏览器标签 `<title>` = 系统名称；`.sub` 说明系统用途
- [ ] 三套主题下正文、边框、次要文字对比正常，没有不可读的颜色
- [ ] DevTools Network 里没有任何外部请求（只有本地文件）
- [ ] 375px 宽度下没有横向溢出

## 交付要求

- 保持文件结构：`index.html` / `style.css` / `app.js`；可新增文件，但不得删除主题逻辑
- 完成后说明：改了哪些文件、页面如何预览（双击 `index.html`）、验收清单逐项结果

## 快速预览

双击 `index.html` 即可在浏览器打开；或在文件夹内执行 `python -m http.server 8000` 后访问 <http://127.0.0.1:8000>。
