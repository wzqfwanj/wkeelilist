# AGENTS.md · 页面开发规范

本文件夹是「黑白极简页面模板」的交付包，**仅面向开发智能体**：用 `index.html` / `style.css` / `app.js` 实现用户要求的系统页面，不要重新设计视觉风格。

## 文件

- `index.html` —— 页头（标题 / 说明 / 主题按钮）+ 空白 `.content` 内容区
- `style.css` —— 设计变量（明 / 灰 / 暗）+ 基础排版
- `app.js` —— 主题切换逻辑（不要改）

预览：浏览器打开 `index.html`；或在文件夹内执行 `python -m http.server 8000` 后访问 <http://127.0.0.1:8000>。

## 必须满足（硬性）

1. **主题切换功能保持不变**
   - 保留右上角图标按钮与 明 / 灰 / 暗 三态循环（明 → 灰 → 暗 → 明），图标随主题变化
   - 保留 localStorage 记忆（键名 `template-theme`）和 `?theme=light|gray|dark`
   - 保留三套 CSS 变量：`:root`（明）、`[data-theme="gray"]`、`[data-theme="dark"]`
   - 不得改成两态、不得删按钮、不得换成文字按钮、不得改 `data-theme` 取值
2. **页面标题替换为系统名称** —— `<h1>` 文本和浏览器标签 `<title>` 都替换
3. **副标题介绍系统做什么** —— `.sub` 写一句话说明（建议 ≤ 30 字）
4. **其余地方自行排版** —— 在 `.content` 内组织内容，可新增 HTML / CSS，但延续本模板设计语言

## 技术与风格约束

- 纯 HTML / CSS / JS，零依赖、零构建；不引入框架、CDN、网络字体、外链图标
- 颜色只用变量 `--bg / --fg / --muted / --line / --hover`，不新增硬编码色值；保持黑白 / 灰调
- 极简：细线分隔、留白、无阴影、无彩色色块
- 响应式：沿用 560px 断点，375px 宽度下不得横向滚动
- 不改动 `app.js` 的主题逻辑与图标定义

## 验收清单（交付前逐条自测）

- [ ] 主题按钮：明 → 灰 → 暗 → 明 循环，图标随主题变化
- [ ] 刷新后主题保持；`?theme=gray` / `?theme=dark` 直接生效
- [ ] `<h1>` = 系统名称；`<title>` = 系统名称；`.sub` 说明系统用途
- [ ] 三套主题下正文、边框、次要文字对比正常
- [ ] Network 面板没有任何外部请求
- [ ] 375px 宽下无横向溢出

## 交付

保持 `index.html` / `style.css` / `app.js` 结构；可新增文件，但不得删除主题逻辑。完成后说明：改了哪些文件、如何预览、验收清单逐项结果。
